# 银狼二次元开场设计（已确认）

## 目标与范围

将目前用 CSS 绘制的天空、山丘、徽章整体换成用户提供的银狼图片，采用参考站的分层入场思路，使用现有 Astro + Svelte + TypeScript 全新实现。网站首页背景、文章和导航保持原有配置。

## 方案选择

- 采用：上下背景图片分别进入，中间透明人物独立浮现，两侧大字随后出现，最后整幕上移。用户在看到这套建议后提供了两张背景和一张透明立绘，素材与此方案匹配。
- 未采用：整张壁纸缓慢缩放。素材要求低，但没有用户希望的人物与背景独立运动效果。
- 未采用：视频开场。需要额外视频素材，对下载体积和手机播放的要求更高。

## 素材与布局

素材目录：`D:\剪辑素材库\2.通用素材\5.图片`。

| 素材 | 用途 | 当前尺寸 |
| --- | --- | --- |
| 银狼壁纸1.jpg | 上半幅，从左侧滑入 | 736 × 428 |
| 银狼背景图.jpg | 下半幅，从右侧滑入 | 1200 × 822 |
| 银狼立绘透明.png | 中间人物，向上浮现并轻微放大 | 736 × 1308 |

沿用紫色主题。背景以 CSS 调整显示位置，尽量保留人物脸部；素材文件不做去水印或内容编辑。立绘保留透明度并适当添加描边和投影，增强轮廓分离。

电脑端大字位于人物两侧；手机端缩小立绘和文字并调整裁切，避免文字压住脸部。沿用“保持好奇 / 开始创造”等现有文字。

## 动作和交互

背景先交错进入，人物随后出现，大字错时进入；约 3.4 秒后开始整体上移，退出约 0.8 秒。图片准备好后再开始计时；加载失败时提供可读的紫色背景和文字，并始终允许跳过。

保留跳过、Esc、重播、自动播放开关、会话记忆、减少动态效果偏好、滚动与焦点恢复。保留本地 `/` 与 GitHub Pages `/ykin/` 的正确路由判断。

## 验收和交付

先在本地浏览器预览桌面和手机效果，让用户确认视觉结果，再发布到现有 ykin 仓库。实现后检查图片加载、首次播放、跳过、重播、开关、路由切换、手机布局及正式路径，并运行项目规定的代码检查与构建。
